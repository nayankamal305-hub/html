# Personal Apps

This repository contains small, privacy-conscious tools.

## UPI Suraksha Check
A Hindi-first, offline-ready UPI scam awareness PWA is available at [apps/upi-suraksha-check](./apps/upi-suraksha-check/). See its [setup, limitations and deployment guide](./apps/upi-suraksha-check/README.md).

The checker runs locally in your browser and does not upload pasted text. It is an educational rule-based aid, not a guarantee that a message or link is safe.
